# Бюджет — учёт доходов и расходов (PWA)

Веб-приложение для iPhone: расходы, доходы и переводы по трём картам (Сбер, Т-Банк, Райф),
итоги месяца и архив. Работает без интернета, без сервера и без регистрации.
Все данные хранятся на телефоне (localStorage).

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | всё приложение (HTML + CSS + JS) |
| `manifest.json` | описание приложения для экрана «Домой» |
| `sw.js` | service worker — офлайн-работа |
| `icon-180.png`, `icon-512.png` | иконка |
| `.nojekyll` | говорит GitHub Pages отдавать файлы как есть (необязателен) |

## Как опубликовать на GitHub Pages

**Через сайт github.com (без программ):**

1. Справа вверху «+» → **New repository**. Имя, например, `budget`. Тип — **Public**
   (на бесплатном тарифе Pages работает только для публичных репозиториев). **Create repository**.
2. На странице репозитория нажмите ссылку **uploading an existing file** и перетащите файлы:
   `index.html`, `manifest.json`, `sw.js`, `icon-180.png`, `icon-512.png`. Нажмите **Commit changes**.
3. **Settings → Pages**. В разделе *Build and deployment*: Source — **Deploy from a branch**,
   Branch — **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты приложение будет доступно по адресу
   `https://ВАШ-ЛОГИН.github.io/budget/` (ссылка появится там же, в Settings → Pages).

**Или через git:**

```bash
git init
git add index.html manifest.json sw.js icon-180.png icon-512.png .nojekyll README.md
git commit -m "Бюджет PWA"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/budget.git
git push -u origin main
```

Затем включите Pages, как в шаге 3.

> Код не содержит ваших финансовых данных: они живут только в телефоне.
> Публичным будет лишь само приложение.

## Как добавить на экран «Домой» на iPhone

1. Откройте ссылку `https://ВАШ-ЛОГИН.github.io/budget/` **в Safari**.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Выберите **«На экран «Домой»»** (если не видно — прокрутите список вниз) → **«Добавить»**.
4. Запускайте приложение с иконки «Бюджет». После первого запуска оно работает и без интернета.

## Важно про данные

- Данные хранятся **только в приложении на экране «Домой»**. Если открыть ту же ссылку просто в Safari,
  там будет отдельное, пустое хранилище.
- Если удалить иконку с экрана «Домой», данные удалятся вместе с ней.
- Регулярно делайте резервную копию: **Настройки → Экспорт в JSON → «Сохранить в Файлы»**
  (или в iCloud Drive). Восстановление — **Настройки → Импорт из JSON**
  (или ссылка «Восстановить из резервной копии» на экране «Баланс на 1 число»).
- Перенос на новый телефон: экспорт на старом → установка на новом → импорт.

## Обновление приложения

Замените файлы в репозитории (Add file → Upload files). Приложение скачает новую версию в фоне
и покажет её при следующем запуске (иногда нужно закрыть и открыть его дважды).
Если меняете **список** файлов, увеличьте номер версии `CACHE` в `sw.js` (например, `budget-v2`).

## Проверка смены месяца (для разработчика)

Месяц определяется по дате устройства. Чтобы проверить смену месяца без ожидания:

- откройте страницу с параметром `?today=2026-10-01` (например,
  `https://ВАШ-ЛОГИН.github.io/budget/?today=2026-10-01`), либо
- впишите дату в константу `TEST_TODAY` в начале скрипта в `index.html`.

Вверху появится оранжевая плашка «Тестовая дата». Смена месяца необратима (прошлый месяц уходит
в архив), поэтому проверяйте на тестовых данных — например, в обычном Safari или на компьютере,
а не в установленном приложении. Перед публикацией `TEST_TODAY` должна быть `null`.
